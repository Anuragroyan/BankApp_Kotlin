# 🏦 Banking App is a Flutter application that simulates basic banking operations, allowing users to deposit, withdraw, check balances, and manage accounts. Account data is stored locally in a bank.json file, with an option to reset the stored data.

# ✨ Features
* 💰 Deposit Money – Add funds to a bank account.
* 💸 Withdraw Money – Withdraw funds from an account.
* 🏦 Account Management – Maintain and manage bank account details.
* 💳 Balance Checking – View the current account balance.
* 💾 JSON Data Storage – Store banking data locally in bank.json.
* 🔄 Data Reset – Reset stored banking data when required.
* 📊 Transaction Updates – Keep account balances updated after deposits and withdrawals.
* 📱 Simple Flutter UI – Clean and easy-to-use interface for banking operations.
